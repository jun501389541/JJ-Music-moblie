# ADR-0006：状态绑定与导航

状态：**提案**。

2026-10-30 PREP-01准备决定：A01/A02最小诊断及纯Dart合同不需要状态/路由第三方包，暂不引入；Riverpod/go_router保留后续UI候选，不锁版本，不用默认页面代视觉确认。理由与范围见[本机计划](../tasks/prep-01-local-plan.md)。

推荐 Riverpod 组织依赖、查询和局部订阅，go_router 组织分支导航与恢复；播放/下载核心为不依赖 Widget 的 Dart 状态机。常驻服务不由页面 provider 自动释放。

比较：BLoC/Cubit 对事件明确，但全页面采用增加样板；ChangeNotifier 适合小页面，不能单独解决多来源异步和后台所有权。go_router 可统一路由及分支返回，完全手写 Router 成本更高；本期不引入第二套路由业务模型。

选择与插件版本需 PREP-01/A01 的阶段决定；不需要把纯模型绑定到状态管理框架。视觉令牌、页面与组件以用户确认稿为依据，不能由库默认样式代替设计。

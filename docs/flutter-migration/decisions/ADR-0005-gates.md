状态：**提案（落实用户的分流与视觉确认要求）**；具体门结果只在 status.md。

本地通过 G-L 即可继续本地业务，正式 UI 另需 G-V。纯资料通过 G-N 不要求音源；在线音频需 G-B/G-S0，发布声明兼容还需授权范围内 G-S1；后台下载再需 G-D。

G-S1 使用最小诊断链，不依赖 P4 产品；G-B 的双轨用假轨/受控媒体，不依赖 P8 完整交叉渐变。消除隐性循环及过重前置。

R3.1澄清（2026-10-30，仍为提案）：G-N最低证据仅B02的TC-46早期资料合同与TC-13底层传输安全。保留TC-23为P4实际无源浏览/失败隔离，TC-33为P4/P6逐平台schema、榜单周期及分页完整性；二者不回指为G-N前置。受控envelope探针通过不提升为平台适配通过。

P1-A先冻结A02共享测试合同/夹具，再让A03/A05使用独立Android/Windows入口。共享断言唯一维护，不复制业务合同；并行分工以任务索引文件归属表为准，不改变架构所有权。

批准与证据分别管理：原型通过不批准生产，用户视觉确认不表示后台可靠，设计批准不授权真实脚本。未授权真实源时不伪造 G-S1，但本地和无源目录可继续。

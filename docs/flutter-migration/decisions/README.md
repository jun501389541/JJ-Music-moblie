# 架构决定索引

状态含义：`用户已确定`仅用于明确方向；`提案`等待评审/实验；`已接受`必须有批准或已授权范围内的决定记录；`替代/废止`保留历史。

每项状态和批准证据只在对应 ADR 更新。本索引只描述主题，不另维护批准状态。

| ID | 主题 |
| --- | --- |
| [ADR-0001](ADR-0001-direction.md) | 用户已确定方向及本轮授权边界 |
| [ADR-0002](ADR-0002-runtime.md) | 共享运行时、恢复、逐轨资源与排他所有权 |
| [ADR-0003](ADR-0003-backends.md) | 后端候选与无 Rust 供应链 |
| [ADR-0004](ADR-0004-data.md) | 共享持久化和迁移 |
| [ADR-0005](ADR-0005-gates.md) | 本地、在线、视觉及真实源门分流 |
| [ADR-0006](ADR-0006-ui-state.md) | UI 状态与导航候选 |

新增决定记录：问题、证据、选项、选择/假设、代价、关联合同/任务/测试、失败出口、决定者及日期。不得只写技术名词。

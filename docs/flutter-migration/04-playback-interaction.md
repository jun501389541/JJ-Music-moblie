# 播放前端与双端交互规格

分类P：布局、尺寸与时长为建议，需 [视觉评审](04-visual-review.md)；不是已批准稿。行为受 [产品规则](03-product-rules.md)约束。任务V01/V02、P2、P3、P6、P7/P8；测试见TC-31—43。

## 信息架构与恢复

Android建议四主目的地：曲库、在线、歌单、管理。曲库含歌曲/专辑/艺术家/流派/目录/最近；在线含歌曲/歌单搜索/榜单/资料；管理含下载/音源/待写入/缺失/数据/设置。高频本地与在线分开，音源不占独立底栏。大屏采用Rail，Windows侧栏；断点按可用空间/字体而非只看OS。

迷你播放条属于壳；完整播放页是覆盖工作区；队列是其附属面板。所有视图使用同一播放状态，不创建第二个播放器。

返回顺序：菜单/对话框→多选→队列→完整播放页→详情父页→主导航根→系统返回。Android返回根不等于停止播放；Windows关闭遵守偏好。

页面保存查询、平台、排序/筛选、游标、首可见条目与偏移、数据修订。返回只恢复视图，不重新load/play。数据修订后核对选择及滚动锚点；失效时回到邻近有效条目。播放位置不塞路由参数。

## 页面与组件

页面：曲库概览/歌曲/目录/专辑与艺术家/流派/最近；在线搜索/榜单/歌单与实体详情；歌单列表/详情/导入和刷新预览；完整播放/歌词/队列历史；下载/音源/待写入/缺失与定位；备份恢复/迁移报告/设置/诊断/更新。

| 组件 | 输入/输出与边界 |
| --- | --- |
| AppShell/AdaptiveNavigation | 导航与安全区；播放区常驻，页面销毁不释放运行时 |
| TrackList/TrackRow | 虚拟化、选择、entry身份、播放意图，不自做解析 |
| SelectionToolbar | 显示范围/数量，提交有序选择 |
| MiniPlayer/NowPlayingLayout | 只订阅权威状态；布局变化不发播放命令 |
| Artwork | 尺寸化解码、占位；旧提色/加载结果按身份丢弃 |
| PlaybackControls/SeekControl | 提交命令，区分accepted/applied/playing与定位预览 |
| LyricViewport | 解析结果、时钟、跟随、浏览、定位，不写文件 |
| QueuePanel | 当前＋两历史，历史恢复由用户主动触发 |
| Source/QualityBadge | 原来源、实际资源及规格依据，不混为一条标签 |
| ErrorRecoveryPanel | 明确阶段、恢复动作和诊断ID |
| DownloadTaskRow | 传输与入库状态分开 |
| AssetWritePreview | 目标、版本、权限、结果；采用不等于写文件 |
| CapabilityControl | 后端不支持则说明/禁用，不能只返回成功 |

## 列表操作合同

| 输入 | Android | Windows |
| --- | --- | --- |
| 单击行 | 页面默认播放意图；多选态则切选择 | 选择，不播放 |
| 行播放按钮 | 页面默认播放意图 | 同左 |
| 双击/Enter | 不要求双击 | 播放该行；搜索试听，普通歌单完整上下文 |
| 长按/右键 | 长按进入多选；更多菜单另有按钮 | 右键菜单，不清除有效多选 |
| Ctrl/Shift/Ctrl+A/Esc | 提供触摸等价操作 | 切选/范围/全选/退出，焦点清晰 |
| 下一首播放 | 当前后插入，不立即切换、不替换队列 | 同左 |
| 加入队列 | 追加尾部 | 同左 |
| 播放所选 | 明确建立所选有序队列；不是搜索默认试听 | 同左 |

搜索“播放已加载N首”；在线列表显示partial/truncated，不把当前页称全部平台结果。抓完整列表必须独立可取消、有上限。普通歌单筛选后点歌仍在完整列表播放；歌曲页可用当前筛选列表，UI要说明。

筛选变化清理不可见选项并提示；筛选/搜索/非自定义排序下禁止持久拖动排序；提供上下移按钮/键盘替代。删除歌单项、移出曲库、删除文件三个动作分开，后者独立确认。定位当前曲若被筛除先提示，不能静默改筛选。

选中用复选+背景；焦点用边框；requested加载、loaded暂停、rendering播放、错误有图标/文字语义，不仅变色。

## 播放页布局与内容压力

建议紧凑宽度约600 logical px以下、600—959中等、960以上宽布局；以实际高度/字体测试修正，不锁死设备类别。Windows初测约480×600逻辑最小窗口，大字体下纵向滚动而不是裁剪控制。DPI与旧Chromium zoom不相乘。

手机竖屏：

```text
收起                  来源 / 更多
           封面
标题（最多两行、完整信息入口）
多歌手 / 专辑
原平台 · 本次来源 · 解析档位/检测依据
时间 ──────●────── 时间
模式   上首   播放/暂停   下首
收藏          歌词          队列
```

手机横屏/平板：

```text
收起                               更多
封面 + 标题/来源       歌词 / 队列
                      当前行与翻译
           进度与核心播放控制
```

Windows宽窗：

```text
侧栏 | 封面与曲目信息 | 歌词（队列侧开）
     | 原条目/本次来源/输出能力
------------------------------------------------
曲目信息  模式 上首 播放 下首  音量 输出 队列
时间 ───────────●──────────────── 时间
```

Windows窄窗：侧栏折叠，封面/歌词切换，信息与控制纵排；连续缩放保留歌词锚点和队列位置。

边界：长标题提供完整信息，不默认永远跑马灯；多歌手保留结构；无封面占位尺寸稳定；未知时长显示`--:--`且无seek能力时禁用；无歌词区分未找到/失败/纯文本；Android优先硬件媒体音量，应用音量可展开；Windows应用/设备音量分开。

## 歌词事件与状态

| 状态/事件 | 行为 |
| --- | --- |
| LRC | 支持当前golden的多时间标签、元数据、offset、异常行；重复时间戳与翻译对应先固定测试，不能顺手改语义 |
| 翻译/罗马音 | 独立轨道和开关，隐藏不删除；不默认近似对齐 |
| 纯文本 | 可阅读，无伪时间戳、同步高亮或seek |
| LX增强 | 仅承诺已定义`[mm:ss.mmm]<offset,duration>`样本，P6验证后启用；其他格式另提案 |
| 自动跟随 | 当前行在阅读区；时钟来自后端锚点，不依赖页面驱动音频 |
| 拖动/滚轮/键盘浏览 | 立即暂停跟随，出现“回到当前歌词”；默认明确恢复，延时自动恢复为可选建议 |
| 点击其他时间行 | 先选择/预览，显式按钮或Windows Enter提交定位；纯文本无此动作 |
| 进度拖动 | 更新本地预览和目标歌词；释放只提交一次seek，后端确认前显示等待 |
| 暂停/后台 | 冻结插值/停不必要绘制，不破坏手动浏览 |
| 来源切换 | 当前曲临时选择与全局偏好分开，旧请求不能覆盖新身份 |
| 采用/编辑/保存 | 采用→待写入；保存预览目标/权限，成功才消费快照；导出副本独立 |

原文/翻译/音译在字体、字重、间距上有层级；活动行不只变色。背景必须有稳定遮罩，高对比度可纯色。屏幕阅读器不随进度持续重读整段。

## 播放处理状态

同时保存用户播放意图与后端处理状态；不要以一个isPlaying概括。

| 状态 | 展示及确认 |
| --- | --- |
| idle | 无当前资源或已停止 |
| matching/resolving | 显示匹配/解析、可取消；不记历史 |
| loading/buffering | 等后端；暂停按钮改变恢复意图，不伪报出声 |
| playing | 当前有效音轨确认；记录一次，静音/设备仍不等于人耳确认 |
| paused | 后端确认；保留资源持有，允许定位 |
| seeking | 目标预览和确认分开 |
| ended | 自然结束，不能和stop/旧轨结束混淆 |
| failed/recovering | 保留原条目/队列，预算内恢复；失败不自动跳曲 |
| reconnecting | R1只重建页面镜像；R2/R3显示对应实际恢复 |
| transitioning | incoming确认才交身份；outgoing保留回滚；字段以C-04为准 |

requestedItem、loadedItem、renderingItem 分开：准备新曲时说明“正在准备B”，不能把旧轨事件当B已播放；系统媒体状态按确认身份更新。渐变时两轨可能都播放，但主显示身份只有一个。

命令反馈消费05 C-02四类信号，applied停止/暂停意图时可仍有后端确认pending，不把它画成已物理停止/已释放。playing使用C-05项目确认及平台映射证据，不由按钮或后端同名布尔值直接推断；具体界面状态仍以本章表为镜像，不另写业务判定。

## 错误与恢复

轻提示建议4秒且可访问性延长；当前播放失败在播放条/播放页持续到恢复或切歌。无源给导入入口但不关资料；缺失给定位；撤权给重新授权；下载给断点/只重试入库；写入失败保留快照；部分平台错误局部展示。持久化失败与播放失败分开，不停止已开始音频。日志只显示诊断ID，不泄露完整URL、令牌/路径。

快速连点只允许最新意图发布；播放中换源按来源失效/新资源合同；输出切换不把命令成功当出声；网络变化不清空队列，恢复有预算，原暂停意图不能被自动重试改成播放。

## 动效/性能建议

迷你展开约240ms缓出，封面/歌词约180ms、队列约200ms，跟随滚动约160—240ms、封面颜色约300ms；都是P，不是观察/实测。反向操作从当前位置接续；切歌取消旧图像/颜色结果。动画绝不阻塞命令。

减少动画、低电量/低性能、后台时停频谱/动态背景和复杂位移。进度约250ms采样只更新局部，状态突变立即更新；频率最终实测。大歌单虚拟化、封面尺寸化解码、有界缓存；歌词/拼音/大JSON适当后台计算；JS忙循环不在UI isolate。详见性能实验。

## 双端输入/可访问性

Android触摸目标建议48逻辑像素；安全区/键盘/系统返回；收起手势只从标题把手开始，不抢歌词滚动。Windows悬停、焦点、右键、多选、滚轮和拖放；输入控件已处理按键不得再拦截。保留窗口内Space、Ctrl左右、左右5秒、Ctrl上下、M、Esc、Ctrl+F行为，不默认全系统抢快捷键。

拖文件不自动授权整个父目录；目录递归导入明确范围。读屏按钮有状态/目标标签；大字体可重排，焦点可恢复；手势/拖动均有替代操作。明暗/高对比度/减少动画必须验证。

## 搜索输入、组合输入与查询寿命

P2/P3先覆盖本地，P4覆盖网络；匹配/排序权威在03，不重复定义算法。F：现有SearchView使用submittedQuery、AbortController和generation隔离提交结果，联想来自同一local-search索引；已读调用链不能证明所有输入法行为已通过。

| 事件 | 规格与反馈（P；TC-50） |
| --- | --- |
| IME composing非空 | 保留输入框编辑态，不以候选文本发搜索/改已提交查询/追加分页；候选用Enter确认不当全局提交或选中联想。兼容平台composing区间暂态，不能只看一次键值 |
| 组合提交完成 | 建议对本地即时筛选/联想防抖150ms（设计初值）；显式搜索页不自动发网络搜索，仍需搜索按钮/真实提交或明确选择建议。一次操作只提交一次 |
| 搜索按钮/非组合Enter | 取消防抖并立即提交当前完整文本；空查询清结果及该查询加载，不启动网络。平台/搜索种类切换复用相同取消和重置规则 |
| 新查询/切平台/页面销毁 | 用C-01请求标识及该查询代次取消旧准备/分页，不能使用playbackGeneration代替查询代次；旧结果/错误/完成不能覆盖新查询。恢复页面只恢复有效revision镜像，不触发播放 |
| 分页 | 固定已提交查询+平台/搜索种类+顺序/筛选+adapter修订+游标，单个分页请求在飞；变化即重置。重复/空页按既有merge与exhausted边界停止，不以无新增项无限请求；部分平台失败保留成功结果 |

内存查询缓存建议每个搜索工作区最多20个已提交查询，按字节/条目双限额；单项上限及TTL在P2/P4用长查询/大页夹具锁定，未设置有限上限不得开启缓存。键包含查询匹配profile、平台/搜索种类、筛选/排序、曲库revision或adapter修订及页/游标；结果只存资料，不存临时URL/头/运行token。原始输入不与不同平台的归一化键混用。换revision即失效或明确标陈旧；用户选择、分页完整性不因缓存命中变为已确认。在线缓存复用07受控传输与TC-33/46规则，不建设独立网络栈；查询缓存默认内存，不额外持久化私人搜索正文。已有历史搜索是否迁移仍按08映射，不能把它悄悄当缓存删除。

防抖是建议，不用于延迟播放/系统控制，也不能改变03明确提交搜索与曲库即时筛选的不同含义。大字体、读屏、焦点和组合输入交互按TC-38/39验证；IME真实端验证与合成输入事件分开。

## 界面文字管理

P2共享UI展开时确定唯一文案目录（建议`lib/presentation/strings/`），由一个负责人维护稳定键、中文文本、占位符/计数/错误动作及语义标签；组件通过键引用，不在Android/Windows复制业务文案。错误code到提示/重试入口映射复用C-01与本章异常规范，不能直接展示平台堆栈或URL。平台确需不同提示通过同一键的适配值处理；不在Kotlin/C++建立另一套产品错误解释。

首发中文即可；集中管理不等于承诺多语言、翻译平台或新增依赖。TC-49检查重复键/占位符与主要组件无散写规则，TC-38/39检查长标题/大字/错误文案布局。后续新增语言需单独范围决定。

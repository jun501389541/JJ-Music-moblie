# 本机媒体Broker合同（M）

分类P/H；任务B01/B02/B06，风险门G-B；测试TC-10—19。当前Electron自定义协议的事实不能证明Flutter本机HTTP通过。

## M-01：监听与能力令牌

- 默认仅`127.0.0.1`，端口由OS分配；IPv6需单独验证`::1`，禁止`0.0.0.0`/通配`::`、自动端口转发。
- 校验实际端点、Host、方法和令牌；不依赖localhost解析，拒绝异常Host/代理形式。客户端本机请求按连接设置绕过系统代理，不改全局配置。
- 至少192位安全随机能力令牌，绑定brokerEpoch、resourceRevision、consumerId与来源授权；不可猜、不可遍历。
- 路由只访问已签发资源，无绝对路径、目录列表、任意URL代理；禁止文件穿越和二次解码绕过。
- 原始媒体URL、签名参数/头留在受控服务；本机令牌不得进UI路由、备份、剪贴板或常规诊断。
- CORS不是认证，默认不开放跨站读取；同用户本机其他进程仍可能访问，因此回环不等于沙箱。

本机与DLNA LAN服务不同，投放不能把本机服务改绑所有网卡；LAN另需设备/会话授权。

## M-02：四种期限及持有

准入TTL、新消费者申请；在用音轨/执行器持有；上游URL有效期；来源/文件授权撤销，分别维护。

准入过期不直接切断合法在用持有；持有不允许继续使用撤权/过期上游。releaseConsumer只处理该消费者及读取者，不影响其他句柄；硬撤销立即阻止所有匹配范围读取。C-04身份提交不触发统一撤销。

UI重连无影响；协调器重建接管存活登记；Broker实际重建旧端点和token全失效。新URL建立新resourceRevision，在途Range不能悄悄换表示；恢复位置与历史确认独立。

## M-03：Android配置

默认远程明文仍关闭，只对实际回环目标配置必要例外；在目标最低/主流系统的release构建和选定原生后端验证。某些原生库未必遵守相同Network Security Config，不能只检查XML。

不能因更高Android版本的localhost默认规则放宽所有支持版本。后端只有全局开放明文才能运行则记缺口，研究DataSource/替代，不能直接接受。[官方配置](https://developer.android.com/privacy-and-security/security-config)。

## M-04：HTTP

| 场景 | 行为 |
| --- | --- |
| GET | 流式有界读取，资源与来源持续校验 |
| HEAD | 返回等价元信息，无body；上游不支持时只允许有界探测，不能偷偷整曲下载 |
| 单Range | 校验起止/总长和上游Content-Range；合法206 |
| 不满足Range | 正确416；已知总长时提供对应范围信息 |
| 畸形/多Range | 明确拒绝；不临时实现多段拼装 |
| 上游忽略Range | 如实200或明确不能恢复，不伪造206/追加 |
| If-Range/ETag/LastModified | 与同一resourceRevision表示对应 |
| 未知长度 | 不伪造Content-Length/可seek能力 |
| 未允许方法 | 405 |
| 令牌不存在/撤销 | 拒绝，错误体不泄露目标 |
| 上游重定向 | 逐跳验证，不向播放器透传远程Location使其绕过Broker |

过滤响应头，禁止把Cookie/认证/CORS或任意上游头原样交给客户端。只转发必要媒体头。

## M-05：上游安全

协议/凭据/host/IP/允许域检查，DNS与实际连接绑定，混合公网私网结果拒绝；每跳重定向重验，次数有限。metadata/link-local/loopback等上游拒绝；自有受控测试端点只在测试配置显式注入，不进入生产通用放行。

文件、图片、歌词、音频分别有字节限额；图片验证MIME和栅格内容。脚本网络走同一受控能力，不把代理保护外推到任意Node网络。

## M-06：流控及初始预算

建议双轨播放最多4传输、下载最多2；等待队列有上限，播放优先但下载不无限饥饿。每流数百KiB级应用缓冲作为原型起点；头等待约12秒、上游读取idle约30秒、媒体总大小沿旧1GiB级上限验证，**均非性能实测或最终固定值**。

慢消费者暂停上游读取，不把整曲积压内存；上游等待与下游背压分开计时，暂停消费不直接算网络故障。HTTP头大小/等待、流/总任务预算和排队均有界；限额错误有诊断。客户端断开实际abort上游和释放槽位；不得连带取消另一轨。

## M-07：取消、重启与日志

CancelRequest、ReleaseConsumer、RevokeSource、StopPlaybackSession、ShutdownBroker五个作用域明确。停止播放不撤下载资源。后端释放确认与流关闭一起推进回收，超时进入故障处置。

Broker重启：新epoch/端口/令牌→旧端点拒绝→重新授权/必要解析→后端重新绑定并恢复；不重复历史，不重放持久URL。下载校验实际part/验证器后再继续。

允许日志：诊断ID、角色、修订、方法/状态、字节/耗时、范围类型、取消原因、资源统计。禁止完整本机/上游URL、token、Authorization/Cookie、脚本文本、歌词正文、私人路径。插件日志、崩溃报告和导出也检查。

## P1证明边界

B06使用假两轨/受控媒体验证持有与取消，不依赖P8完整渐变；B05b用最小诊断播放器，不依赖P4正式页面。G-B只证明指定后端/平台/条件下合同；更换后端或生产网络组件需重验。

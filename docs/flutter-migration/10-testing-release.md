| Android渠道、更新责任与签名保管 | 首个对外发行前（可能P3）在相应ADR/发行计划记录用户选择 | 本地日用MVP可未发布；不为等P8而省略首次安全验收。密钥由用户控制，仓库/普通交接仅记证书标识和摘要 |
| Windows安装/便携/商店、关联注册/卸载清理 | P7包装集成前、P8正式发行再验；若有会改变系统能力的包装选择需提前核查 | 只实现获选形态；便携多实例不支持见03，不能把zip存在当便携数据策略完成 |
| 系统备份配置与恢复边界 | 首个对外Android包前按08 B节；Windows受控目录迁移在P7前 | 未证明白名单则按08默认排除并说明不支持，不能沿用模板默认项 |

Windows包装影响身份和系统扩展能力，不能把某一种形式当所有API的必要条件或通用解法；进入包装阶段按实际所用API/形态复核[微软官方包装说明](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/packaging/)（2026-10-30核阅）。Android系统备份政策依据与厂商差异只在08维护；目标SDK/商店政策在实施阶段重新查官方资料，不在此锁死平台政策或版本。

二进制下载/验签/安装失败时，区分尚未触碰数据与启动后已升级schema。更新包在验证前不切换，失败保当前可用成品及已确认的安全状态，不重试执行未知包。**DB升级失败**沿08临时副本/一致备份/校验/切换流程，不能把已替换二进制回退当数据自动回退。旧版本只允许打开其明确支持的schema范围；不支持的新schema拒绝写入。若要运行旧版本，应停止所有writer，恢复其配套一致快照到隔离目录后再验证；升级后新产生数据先保留，不能用旧快照覆盖唯一副本。降级转换不是首版默认功能。

每次发行需声明：二进制能否回装、其可读schema/备份版本、恢复步骤及可能丢失的升级后增量；只保留旧安装包不算可回退。TC-53/37/45分别提供相应证据。首次Android对外发行在P3发生时，只检查所启用能力和手动分发路径，不提前承诺P7/P8全部高级/Windows能力通过。

## 最小诊断与维护

P3提供用户主动本地导出最小诊断的建议；P4/P5/P7仅增对应能力字段，不建设遥测/运维服务，不扩大P1。本节是日志保留与导出规格唯一来源。已有OnlineDiagnostics白名单、2MiB/500条及保存入口事实见01，脱敏基础合同引用TC-18和07-M日志规则；本节不把旧诊断描述为未实现。

最小包包含：产品版本/完整构建提交（脏构建明确标识）、平台/OS与后端/插件构建摘要、C/M/D/数据库schema及支持profile版本、启用能力、错误code/stage/retryable、同一次导出内重映射的请求/事件序号及必要epoch关系、操作时序/相对时间、活跃流/handle/下载/缓存字节等聚合计数。按阶段缺失的功能明确unsupported/not-collected；不为凑字段导出私人数据或虚构计数。

默认不记录私人曲名/歌词正文、脚本文本、源私有配置、绝对路径/URI、查询正文、完整媒体URL/头/令牌；曲目/源/文件身份如需关联只在包内生成不反推原值的短期序号，不用永久路径哈希代替脱敏。任意插件异常message/stack可能含秘密，捕获与导出两次按白名单重建，无法安全结构化则只保错误类别。诊断事件的版本化封装在对应阶段展开时先更新权威合同/证据格式，UI和原生不各写一份错误模型。

建议初值：结构化诊断总磁盘上限2MiB、最多500事件、最长7天，任一达到先淘汰最旧；时钟回拨或无法确认日期时仍由条数/字节硬上限约束，过期判断保守清除不可靠时间项。内存缓冲、单事件及导出临时包也有界，具体上限在P3计划锁定。日志满/损坏/关闭不能使播放或关键DB操作失败；磁盘不足停止记日志而不循环重写。不把P1临时试验日志改为完整维护系统。用户自行导出的文件由用户管理，不随应用轮转删除，也不进系统备份。

导出流程：用户主动触发→冻结快照→生成脱敏预览（字段类别/事件数/时间范围/估计体积与排除项）→用户选择位置→有限临时写入/成功发布；取消不写最终包，失败保留可复现的安全错误类别并按08回收临时残留。预览是新增交互建议，随V01/V02覆盖设置/错误状态的相应稿件确认，不新增全局批准门。应用不默认上传、不后台发遥测；未来若需发送另立范围，不借“导出”自动发送。TC-55用合成敏感标记、嵌套异常、超大事件、满盘和取消检查最终包及预览。

测试失败的维护证据复用evidence/README与agent-workflow交接：关联完整SHA/脏差异、工具/合同版本、自有fixture摘要、设备/编译/网络条件、准确步骤/命令和cwd、预期与实际事件顺序/退出码、未验限制。私人场景未获授权不采集；无fixture/实际输入只能标不可完整复现，不把聊天说明当证据。TC-55检查诊断产物，DOC-03/04/05检查证据关联；不新建重复的任务状态库。

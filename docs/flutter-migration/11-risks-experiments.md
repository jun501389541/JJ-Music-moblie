## 待确认列表

- 架构提案、具体阶段实施范围：等待用户审核；方向已确定不重复争论。
- 最低Android/Windows版本、ABI、设备型号和实际系统：PREP-01登记依赖矩阵再决定，不编造可用设备。
- 共享状态管理/数据库/后端候选和二进制版本：对应ADR提案，按实验接受。
- 双端视觉稿版本与交互意见：V01/V02，尚未发生。
- 真实脚本与有限曲目授权：B05前独立登记，不能把公开源码当任意执行许可。
- Android MVP是否在首次发行前增加在线：建议分开，本地MVP不被源阻塞；有在线声明需对应证据。
- Windows替换时可接受的实验/暂缓能力：P9差距审核，不静默删除。
- 六项横向边界为R3.2提案：存储预算数值/扫描提供方上限/拼音排序兼容在P2/P3计划落实；这不是增加P1探针或全局门。
- Android首个对外包前选应用ID/分发渠道/用户保管签名及系统备份支持范围，Windows P7前选安装/便携形态；不预先承诺商店政策或可降级读库。
- 文件关联/Android分享及诊断预览/导出UI可延期或不采用；需保留03的行为变更标记与工作包差距，不能自动升级首版必需。

设备/工具不可用时允许继续内容见agent-workflow；必须保留未通过的验收，不用猜测补空。

R4执行定位：本页保留风险及问题定义，不另维护任务依赖或结果。上表旧WP均经[历史范围映射](tasks/phase-backlog.md)定位到具体任务，不能领取WP；当前前置以[任务索引](tasks/README.md)为准。实验步骤、成功/失败分支、字段确定者及原型保留/改造/移除时点见[条件分支](tasks/conditional-branches.md)。例如X9由P5-05/06/07与P7-01，X10由P8-01/02/03/04，X11由P8-05/06，X20由A02与P2-06，X21由P2-00、P5-00、P6-00及其文件任务落实；此处引用不增加新门。

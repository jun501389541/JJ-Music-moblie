## P8-00：冻结高级能力和发布验收

- 目标与用户可见结果：音频投放性能有测量范围与出口
- 依据与产品规则：避免高级能力未证导致业务或数据语义错误；PR-16/19/20/24。语义以[03](../03-product-rules.md)为准。
- 关联需求：R-16、R-17、R-18、R-19；需求定义及任务/核心测试映射唯一见[12](../12-requirements-traceability.md)。
- 范围与非目标：不因竞品支持而承诺全部
- 前置与授权：仅以[任务索引](README.md)的P8-00行及[status](../status.md)为准；本手册不授权开工。对应阶段范围已授权；仅启用已满足能力门的功能；已授权范围内常规修复持续完成，不逐步重新请示。
- 环境与自有数据：Git、UTF-8编辑/定点检索及文档检查工具；只读核对现有SDK，不安装、不运行产品。 数据/规模：自有夹具：核心证据齐；高级能力未证；取消实验；后端包装同时改。
- 输入输出契约：06能力、09 P8、10实验；开工记录文档R4及实际合同修订/文件摘要。公共消费字段由P8-00按前置证据锁定；消费前未冻结不进入相应代码改动。本任务负责的实验输出不要求预先通过，可在安全输入/授权满足后做限定实验；不把本文路径当已存在。 输出：冻结高级能力和发布验收的实现/限制与可复现用例结果。
- 允许文件与负责人：既有本目录相关任务/ADR/交接与本任务证据；不改产品。 P8-00执行者只负责上述范围，共享模型/schema/锁/构建/设计令牌由[归属表](contracts-ownership.md)指定角色串行整合，不自行改。新增目录外文件先回写当批allowlist，不默认全仓库。
- 正常/异常/取消/并发场景：正常=核心证据齐；异常=高级能力未证；取消=取消实验；并发=后端包装同时改。逐项记录实际覆盖；规划任务只审条件分支，未运行或未发生项保留未验，不为凑齐制造测试。
- 验证方法：cwd <repo>；按DOC-01—05检查实际文件/引用/依赖和计划清单，不为规划强行跑产品套件。 TC=DOC-01—05/TC-42—45规划，等级沿10注册表；命令/编译模式及预期在当批证据写明。
- 完成标准与证据：不假报无缝独占；先定阈值；生产接口单一；四类场景按本任务适用TC留实际结果；保存`evidence/P8-00/<batchId>.md`（计划新增），含完整代码SHA/未提交差异、合同/稿件版本、自有fixture摘要、准确cwd/命令/步骤/退出码/限制及分支与集成结果。适用TC每个子场景可定位，未验项不得记通过。

- 独立可继续工作：索引中其他文件不重叠且前置已满足的任务；仅限已有授权且前置满足。
- 下一任务：协调者据索引选择已满足的后继；建议检查P8-01—08按能力，不自动授权/跳阶段。

# P5：详细任务手册—歌单、下载与迁移

本页为R4实际填写的任务；状态/授权只在[status](../status.md)，前置唯一在[索引](README.md)。所有Flutter/原生路径均为**计划新增或未来真实树待核**，本轮没有工程；未选依赖不预写插件方法。阶段入口只把既有手册与当时真实原型/树/工具对齐，不重新设计整套架构，也不增加审批门。在已授权阶段内可连续完成符合前置的独立小批次，独立视觉/私人源/发布边界保留。

共同读取：[批次运行与结果术语](../agent-workflow.md)、[契约/文件归属](contracts-ownership.md)、[条件分支](conditional-branches.md)、[测试权威](../10-testing-release.md)。每个任务把适用TC拆到自己的正常/异常/取消/并发子用例，局部通过不把整TC或风险门自动标通过。

## P5-00：冻结歌单、下载与迁移独立批次

- 目标与用户可见结果：歌单/迁移先做，下载按对应门开工
- 依据与产品规则：避免下载/标签能力未定导致业务或数据语义错误；PR-06/12/13/22/24。语义以[03](../03-product-rules.md)为准。
- 关联需求：R-12、R-13、R-14、R-17、R-26、R-35；需求定义及任务/核心测试映射唯一见[12](../12-requirements-traceability.md)。
- 范围与非目标：只规划，不读真实旧资料或要求所有在线先完成
- 前置与授权：仅以[任务索引](README.md)的P5-00行及[status](../status.md)为准；本手册不授权开工。对应阶段范围已授权；仅启用已满足能力门的功能；已授权范围内常规修复持续完成，不逐步重新请示。
- 环境与自有数据：Git、UTF-8编辑/定点检索及文档检查工具；只读核对现有SDK，不安装、不运行产品。 数据/规模：自有夹具：正式Repository可用；下载/标签能力未定；暂停子范围保计划；schema/发布/源同时修改。
- 输入输出契约：08 schema/S/O、07 D、09 P5；开工记录文档R4及实际合同修订/文件摘要。公共消费字段由P5-00按前置证据锁定；消费前未冻结不进入相应代码改动。本任务负责的实验输出不要求预先通过，可在安全输入/授权满足后做限定实验；不把本文路径当已存在。 输出：冻结歌单、下载与迁移独立批次的实现/限制与可复现用例结果。
- 允许文件与负责人：既有本目录相关任务/ADR/交接与本任务证据；不改产品。 P5-00执行者只负责上述范围，共享模型/schema/锁/构建/设计令牌由[归属表](contracts-ownership.md)指定角色串行整合，不自行改。新增目录外文件先回写当批allowlist，不默认全仓库。
- 正常/异常/取消/并发场景：正常=正式Repository可用；异常=下载/标签能力未定；取消=暂停子范围保计划；并发=schema/发布/源同时修改。逐项记录实际覆盖；规划任务只审条件分支，未运行或未发生项保留未验，不为凑齐制造测试。

- 下一任务：协调者据索引选择已满足的后继；建议检查P5-01/P5-05；下载门满足再P5-02，不自动授权/跳阶段。

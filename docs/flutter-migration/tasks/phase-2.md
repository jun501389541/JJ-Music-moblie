# P2：详细任务手册—本地生产闭环

本页为R4实际填写的任务；状态/授权只在[status](../status.md)，前置唯一在[索引](README.md)。所有Flutter/原生路径均为**计划新增或未来真实树待核**，本轮没有工程；未选依赖不预写插件方法。阶段入口只把既有手册与当时真实原型/树/工具对齐，不重新设计整套架构，也不增加审批门。在已授权阶段内可连续完成符合前置的独立小批次，独立视觉/私人源/发布边界保留。

共同读取：[批次运行与结果术语](../agent-workflow.md)、[契约/文件归属](contracts-ownership.md)、[条件分支](conditional-branches.md)、[测试权威](../10-testing-release.md)。每个任务把适用TC拆到自己的正常/异常/取消/并发子用例，局部通过不把整TC或风险门自动标通过。

## P2-00：冻结本地生产批次与原型处置

- 目标与用户可见结果：后续本地功能有真实工具/目录/锁序和原型替换计划
- 依据与产品规则：P1证明协议不等于生产存储/后端已全部可用；PR-17—24。语义以[03](../03-product-rules.md)为准。
- 关联需求：R-01、R-08、R-13、R-17、R-26、R-27、R-28、R-34、R-35；需求定义及任务/核心测试映射唯一见[12](../12-requirements-traceability.md)。
- 范围与非目标：只展开P2与处置A/B原型；不实现产品，不等待在线源
- 前置与授权：仅以[任务索引](README.md)的P2-00行及[status](../status.md)为准；本手册不授权开工。G-L；正式UI任务另需G-V；已授权范围内常规修复持续完成，不逐步重新请示。
- 环境与自有数据：Git、UTF-8编辑/定点检索及文档检查工具；只读核对现有SDK，不安装、不运行产品。 数据/规模：A系列实际日志、当前SDK/原生资产清单、自有目录/音频样本清单。
- 输入输出契约：05 C-01—06、08 S/L/O、ADR-0002/04/06；开工记录文档R4及实际合同修订/文件摘要。公共消费字段由P2-00按前置证据锁定；消费前未冻结不进入相应代码改动。本任务负责的实验输出不要求预先通过，可在安全输入/授权满足后做限定实验；不把本文路径当已存在。 输出：批次allowlist、锁/资源表、正式端口实现清单、原型保留/改造/移除决定。
- 允许文件与负责人：既有本目录相关任务/ADR/交接与本任务证据；不改产品。 P2-00执行者只负责上述范围，共享模型/schema/锁/构建/设计令牌由[归属表](contracts-ownership.md)指定角色串行整合，不自行改。新增目录外文件先回写当批allowlist，不默认全仓库。

- 验证方法：cwd <repo>；按DOC-01—05检查实际文件/引用/依赖和计划清单，不为规划强行跑产品套件。 TC=DOC-01—05、TC-05/57/58规划，等级沿10注册表；命令/编译模式及预期在当批证据写明。

- 独立可继续工作：PREP-02/V01范围内视觉工作；仅限已有授权且前置满足。
- 下一任务：协调者据索引选择已满足的后继；建议检查P2-01，不自动授权/跳阶段。

- 目标与用户可见结果：Windows有功能/包装/迁移计划
- 依据与产品规则：避免包装输出未定导致业务或数据语义错误；PR-15/16/24。语义以[03](../03-product-rules.md)为准。

- 范围与非目标：不等P6所有平台，不宣布替换旧端
- 前置与授权：仅以[任务索引](README.md)的P7-00行及[status](../status.md)为准；本手册不授权开工。对应阶段范围已授权；仅启用已满足能力门的功能；已授权范围内常规修复持续完成，不逐步重新请示。
- 环境与自有数据：Git、UTF-8编辑/定点检索及文档检查工具；只读核对现有SDK，不安装、不运行产品。 数据/规模：自有夹具：本地schema证据齐；包装输出未定；暂停保旧版；多人改原生配置。
- 输入输出契约：09 P7、08迁移、10分发；开工记录文档R4及实际合同修订/文件摘要。公共消费字段由P7-00按前置证据锁定；消费前未冻结不进入相应代码改动。本任务负责的实验输出不要求预先通过，可在安全输入/授权满足后做限定实验；不把本文路径当已存在。 输出：冻结Windows补齐与并行试用的实现/限制与可复现用例结果。
- 允许文件与负责人：既有本目录相关任务/ADR/交接与本任务证据；不改产品。 P7-00执行者只负责上述范围，共享模型/schema/锁/构建/设计令牌由[归属表](contracts-ownership.md)指定角色串行整合，不自行改。新增目录外文件先回写当批allowlist，不默认全仓库。

- 下一任务：协调者据索引选择已满足的后继；建议检查P7-01/P7-02/P7-04，不自动授权/跳阶段。

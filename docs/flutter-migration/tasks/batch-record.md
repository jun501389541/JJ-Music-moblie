# 单批证据与交接填写单

这是将来每批的填写格式，不是假完成记录；实际放入evidence/<任务ID>/<batchId>.md（计划新增）。本页不维护状态、批准或合同字段。每个任务的实际步骤已在手册填好，不能仅交此空表代实现。

| 字段 | 必填内容 |
| --- | --- |
| 任务/结果 | 稳定ID、本批一个可审查结果、授权记录与允许/非目标 |
| 实际基线 | 分支/完整SHA、目标工作区、开始前未提交文件/摘要；本批实际差异/新增文件及摘要，不能只写commit但漏未提交修改 |
| 输入版本 | 文档/合同C/M/D、schema/profile、稿件版本或摘要；尚未冻结项及负责任务 |
| owner | 执行者、协调者、共享文件维护角色；与其他任务冲突如何处理 |
| 数据/环境 | 自有fixture路径/来源/许可/摘要、设备OS/ABI/后端版本、编译模式/网络；无私人内容 |
| 实施步骤 | 实际执行与手册偏差；为什么必要、谁可决定，未完成停在哪一步 |
| 验证 | 每场景TC/输入/准确cwd/命令或人工操作/预期/实际/退出码/证据路径；not-run/failed/partial/N/A/passed及理由 |
| 两端/集成 | Android与Windows分别结果；分支自测还是目标工作区集成、目标基线与重验；无集成资源保持review |
| 决定/原型 | 接口变化影响任务/兼容/重验，实际备选选择与依据；原型保留测试/改造/移除及文件 |
| 回退/限制 | 失败现场、最后有效快照、仅本批可撤范围，未验与风险，哪些独立任务可继续 |
| 交接 | 已完成证据/在做文件及余项/未跑原因/下一任务；仍需用户决定事项含推荐、替代、影响、最晚点 |

执行者交独立记录；协调者核验后串行更新status/handoff。字段不适用写原因，不能空白当成功，不记录密钥、完整媒体URL、脚本或私人音乐/歌词正文。

# 新增/维护任务的字段规范

现有全部任务已经实际填在各阶段手册，不能仅复制此页空表代交付。后续维护或拆子任务才用本规范；先登记稳定ID/唯一依赖/owner和实际允许文件，不复用已完成或废止ID。

1. 目标与用户可见结果，为什么需要及对应PR/R。
2. 范围/非目标，前置与门/授权引用唯一索引。
3. 环境/工具/设备/自有数据及不存在时的边界。
4. 输入/输出及消费的C/M/D/schema/profile/稿件版本；未知字段的负责任务/确定时点。
5. 已存在路径先核，计划新增显式标注，不能把整仓默认可改；共享角色只看归属表。
6. 分步表：目的、动作、预期、失败处理；覆盖接手/核契约/选场景/实现/相关验证/查差异/证据交接。
7. 正常/异常/取消/并发四类用例，适用TC与设备/自动/人工证据等级。
8. cwd/平台/前置/实际命令或人工步骤及预期；未建入口不冒已运行。
9. 完成标准和必需证据、分支/目标工作区集成层级。
10. 条件分支、原型保留/改造/移除、可自行修/已批备选/必须停的界线。
11. 回退/停止、可独立继续事项、准确未完成记录。
12. 下一任务只建议，依赖/授权仍看索引/status；不自动提交推送或发布。

接口变动先更新权威和受影响消费者，状态/批准只在各权威位置。已授权批次内常规细节agent自行处理；复杂行为先复现/红测试，纯文档/简单样式按影响验证，不生造测试或反复全量检查。
